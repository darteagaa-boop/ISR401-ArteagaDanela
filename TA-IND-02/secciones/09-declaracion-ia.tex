\section*{Declaración de uso de inteligencia artificial}

En este trabajo se usó Claude (Anthropic), modelo Sonnet 5.5, como herramienta de apoyo para revisar aspectos ortográficos y gramaticales, así como para identificar posibles errores de compilación. Además, se utilizó para resolver dudas puntuales relacionadas con la escritura de expresiones, caracteres especiales y elementos del código en LaTeX que pudieran afectar la correcta compilación del documento.
